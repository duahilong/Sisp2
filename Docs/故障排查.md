# 故障排查

本文档面向实际运行 Sisp 时的问题定位。优先查看日志和 worker 结果文件，再根据错误码判断失败阶段。

## 1. 日志位置

默认日志目录：

```text
%LOCALAPPDATA%\Sisp\logs
```

日志文件名形如：

```text
sisp_20261020_213000_12345.log
```

日志包含：

- PowerShell 脚本内容
- PowerShell 退出码
- stdout / stderr（过长时截断）
- 每个步骤的通过/失败和耗时
- 未预期异常的堆栈

自定义目录：

```powershell
py .\app\main.py --log-dir D:\Sisp\logs
```

关闭文件日志：

```powershell
py .\app\main.py --no-log
```

## 2. 先做只读检查

在真实写盘前，建议依次执行：

```powershell
# 检查配置、路径是否存在、文件/目录类型是否正确
py .\app\main.py --check-config -j .\json\win11.json

# 只列出硬盘，不写盘
py .\app\main.py --list-disks

# 预览将执行的 PowerShell/命令，不写盘
py .\app\main.py --dry-run -j .\json\win11.json
```

`--check-config` 会校验：

- `win_gho` 是文件
- `gho_exe` 是文件
- `bcd_exe` 是文件
- `software_file` 是目录

## 3. 常见问题

### 3.1 提示“当前程序未以管理员权限运行”

- 关闭当前终端。
- 右键“以管理员身份运行”PowerShell 或 Windows Terminal。
- 重新执行命令。

`--list-disks`、`--check-config`、`--dry-run` 仍可能需要读取磁盘信息，建议同样使用管理员终端。

### 3.2 提示“PowerShell 不可用”

- 在终端执行 `powershell -NoProfile -Command "Write-Output ok"`。
- 检查是否被安全软件拦截。
- 检查 `powershell.exe` 是否在 `PATH` 中。
- 查看日志中的 PowerShell stderr。

### 3.3 提示“配置文件不存在”或“解析失败”

- 确认 `-j` 指向的文件存在。
- JSON 必须为 UTF-8 编码，根节点必须是对象。
- 使用 `--check-config` 获取具体字段错误。
- 相对路径会相对 JSON 文件所在目录解析。

### 3.4 目标硬盘不可操作 / 受保护

常见原因：

- 系统盘或启动盘
- 离线盘
- 只读盘
- 型号命中 `excluded_disk_names`

使用 `--list-disks` 查看“状态”和“原因”列。确认硬盘型号后检查配置中的 `excluded_disk_names`。

### 3.5 多盘模式下主窗口一直等待 worker

现象：主窗口提示“等待 worker 结果并汇总...”，但长时间没有汇总。

排查：

1. 查看 worker 窗口是否仍在运行，是否卡在某个 PowerShell 操作。
2. 检查 `--result-dir`（或默认临时目录）下是否生成 `disk_<n>.json`。
3. 查看 worker 窗口和主窗口日志。
4. 如果 worker 窗口已关闭但仍无结果，可能是结果文件写入失败；日志中会有“写入 worker 结果失败”。
5. 可用 `--worker-result-timeout` 调整等待上限（单位秒），超时后主窗口会为未完成 worker 生成失败汇总。

### 3.6 worker 结果文件无法解析

结果文件由 worker 原子写入（先写 `.tmp` 再替换）。如果看到“读取 worker 结果失败”：

- 确认文件不是手工编辑/截断的。
- 删除该结果文件后重试对应 worker。
- 查看日志中的 JSON 解析错误。

### 3.7 Ghost 写入失败

检查：

- `gho_exe` 是否存在且为文件。
- `win_gho` 是否存在且为文件。
- 目标 Windows 分区盘符是否正确。
- Ghost 是否被安全软件拦截。
- 查看日志中的 Ghost 命令、退出码和输出。

### 3.8 bcdboot 创建引导失败

检查：

- `bcd_exe` 是否存在且为文件。
- EFI 分区盘符和 Windows 分区盘符是否正确。
- EFI 分区是否已格式化为 FAT32。
- 查看日志中的 bcdboot 命令和输出。

### 3.9 盘符不足

程序会为每块盘分配 4 个盘符（EFI、Windows、Data1、Data2）。如果可用盘符不足：

- 减少同时处理的硬盘数量。
- 释放部分已占用盘符。
- 检查是否有残留的“幽灵盘符”。
- 本版本不再自动调用 `mountvol /d`。若确认存在残留挂载点，请先人工核实归属再手动清理；程序遇到被占用盘符会安全中止，而不是卸载卷。

### 3.10 控制台中文乱码

- 使用 Windows Terminal 或 PowerShell 7。
- worker 进程已设置 `PYTHONUTF8=1`、`PYTHONIOENCODING=utf-8`。
- 日志文件使用 UTF-8 编码。
- 如仍有乱码，检查系统代码页和终端字体。

## 4. 错误码

| 错误码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 1 | 运行前检查失败 |
| 2 | 硬盘初始化失败 |
| 3 | 分区/格式化失败 |
| 4 | Ghost 镜像写入失败 |
| 5 | 目录拷贝失败 |
| 6 | 引导记录创建失败 |
| 7 | 验证失败 |
| 8 | 配置错误 |
| 9 | 硬盘受保护 |
| 10 | 硬盘身份不一致 |
| 11 | 路径遍历风险 |
| 12 | 未预期异常 |
| 13 | 用户取消 |
| 14 | worker 结果缺失/超时 |

## 5. 收集问题信息

提交问题前建议收集：

```powershell
py .\app\main.py --version
py .\app\main.py --check-config -j .\json\win11.json
```

以及：

- 最近的日志文件
- worker 结果 JSON
- 出问题的硬盘编号、型号和操作阶段
- 是否可稳定复现

请勿在公开渠道上传包含敏感路径、序列号或镜像信息的完整日志，必要时先脱敏。
