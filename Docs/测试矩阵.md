# 测试矩阵

本文档说明 Sisp 当前自动化测试覆盖范围、运行方式和真实磁盘验证边界。

## 1. 运行方式

全量测试：

```powershell
py -m pytest
```

查看完整统计（覆盖 `pytest.ini` 中的 `-q`）：

```powershell
py -m pytest -o addopts="" --tb=short
```

带覆盖率：

```powershell
py -m pytest -o addopts="" --cov=app --cov-report=term-missing
```

代码检查：

```powershell
py -m ruff check app tests
```

默认安全测试入口（pytest + 无效输入报告）：

```powershell
py .\tests\run_all.py
```

CI 配置见 `.github/workflows/ci.yml`，在 Windows 上执行：

- `ruff check app tests`
- `pytest --cov=app --cov-fail-under=70`
- `PyInstaller --clean --noconfirm Sisp.spec`
- `PyInstaller --clean --noconfirm SispGUI.spec`（独立 GUI 构建 job）

## 3. 真实磁盘验证边界

默认测试**不会**：

- 执行 `Clear-Disk`
- 执行 `Initialize-Disk`
- 执行 `New-Partition`
- 执行 `Format-Volume`
- 写入 Ghost 镜像
- 修改真实硬盘分区

需要真实磁盘验证时，请在测试机/虚拟机中手动执行，并至少覆盖：

1. `--version`
2. `--check-config`
3. `--list-disks`
4. `--dry-run`
5. 单盘完整流程
6. 两盘及以上 worker 流程
7. 失败注入（错误镜像路径、错误 Ghost 路径、错误 bcdboot 路径）
8. 系统盘/启动盘保护
9. 盘符不足、盘符被占用、残留幽灵盘符场景
10. 目标盘缺少 `UniqueId` / `SerialNumber` 时拒绝写盘
11. GHO/工具/源目录/配置/日志目录位于目标盘时拒绝执行
12. Ghost/拷贝/bcdboot 前盘符归属变化时中止
13. worker 结果超时/缺失场景
14. GUI：`python -m app.gui` 启动并完成提权
15. GUI：扫描硬盘 → 生成计划 → 计划确认页阻断项门禁
16. GUI：dry-run 跑到结果页，日志与监控表实时刷新
17. GUI：单盘完整流程
18. GUI：多盘错峰执行、取消中状态和结果汇总
19. GUI：关闭窗口时任务仍在执行的协作取消与自动退出
20. GUI：`SispGUI.exe` 双击触发 UAC 并从发布目录正常启动

## 5. 新增测试约定

- 测试文件命名：`test_*.py`
- 测试必须可在无管理员权限、无真实硬盘的 CI 环境中运行。
- 涉及真实 PowerShell 的测试通过注入 runner 或 monkeypatch `subprocess` 完成。
- GUI 测试使用 `QT_QPA_PLATFORM=offscreen`，不启动真实事件循环；未安装 PySide6 时通过 `pytest.importorskip` 跳过。
- 新增主流程步骤时，同步更新：
  - `tests/test_minimal_main_flow.py` 的成功/失败路径
  - `tests/test_observability.py` 的日志/结果断言
  - 本文档的覆盖矩阵
